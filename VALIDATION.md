# Валидация AI-buddy и локального демо

Дата: 15 ноября 2026. Окружение: локальный Go + mock-service + Vite; для предметных вопросов настроена бесплатная `nvidia/nemotron-3.5-lightning:free` через OpenRouter.

## Матрица проверок

`evaluate_buddy.py` поднимает **изолированные** Go и mock-service на свободных портах с временными JSON-данными, для каждой позиции меняет назначение через mock API и последовательно создаёт/согласует заявку. Он не изменяет работающий демо-стенд. Без флага `--live` модель **не вызывается**; с флагом возможно до 21 предметного вопроса и одного серверного повтора на каждый (до 42 запросов провайдеру). При HTTP 503/429 прогон останавливается, частичный JSON сохраняется.

| Позиция | `not_created` (6) | `pending` (3) | `approved` (3) |
| --- | --- | --- | --- |
| backend | приветствие, доступ, следующий шаг, обучение, отказ на код и офтопик | статус MCP, блокировка шага, связь с наставником | статус MCP, следующий шаг, обучение |
| frontend | те же проверки, но по плану frontend | те же проверки, но заявка frontend | те же проверки, но следующий шаг frontend |
| analyst | те же проверки, но по плану analyst | те же проверки, но заявка analyst | те же проверки, но следующий шаг analyst |

Итого **36 кейсов = 15 детерминированных + 21 модельный**. Автоматические проверки: HTTP 200, непустой ответ, ожидаемый вызов MCP и отсутствие модели на детерминированном пути, требуемые ID источников, статус/ресурс/ключевые фразы. Источники сверяются с ответом Go, но этот чек не доказывает смысловую достоверность произвольного текста модели.

## Результаты

### Исторический полный прогон до нормализации цитат и retry (отчёт предыдущего агента)

| Позиция | Пройдено | Из них model-кейсов |
|---|---:|---:|
| backend | 10/12 | 5/7 |
| frontend | 11/12 | 6/7 |
| analyst | 10/12 | 5/7 |
| **Итого** | **31/36 (86,1%)** | **16/21 (76,2%)** |

Детерминированные кейсы: 15/15. Пять model-кейсов получили безопасный fallback вместо проверенного ответа:

- `backend/not_created/access`
- `backend/not_created/next`
- `frontend/approved/next`
- `analyst/not_created/next`
- `analyst/pending/blocked`

Сырой JSON этого исторического полного прогона не сохранён, поэтому его агрегаты **не воспроизводятся из приложенных артефактов**. После него добавлены нормализация сокращённых ID источников и один повтор при отклонённом ответе; приведённые 31/36 и задержки модели относятся **только к версии до этих изменений**. Исторически сообщались median ≈831 мс, p95 ≈1493 мс, max ≈3262 мс по успешным модельным ответам; исходных замеров нет.

### Проверка текущей версии

`python3 evaluate_buddy.py --delay 0 --output validation/deterministic.json` → **15/15** на всех трёх позициях и трёх состояниях; сырой результат в [`validation/deterministic.json`](validation/deterministic.json).

`python3 evaluate_buddy.py --live --output validation/live.json` → **прерван после 2 кейсов**: приветствие backend прошло, первый предметный вопрос вернул HTTP 503 «Лимит запросов к модели исчерпан». Полный текущий результат **неизвестен**; 1/2 нельзя выдавать за оценку качества. Сырой результат в [`validation/live.json`](validation/live.json). После восстановления квоты повторить полный прогон и отдельно вручную оценить содержательные утверждения для каждой позиции и состояния.

### Браузерные метрики

`measure_browser.mjs`, Chromium headless 141 (Playwright 1.56.1), viewport 1280×900, Vite dev server на loopback, Go и mock на выделенных портах, чистый назначенный план backend, 10 повторов 15 ноября 2026. Время клика измерено **в браузере** от доверенного click event до видимого DOM-состояния после ближайшего `requestAnimationFrame` и следующей задачи (приближение возможности покраски, не аппаратный timestamp пикселя). Время открытия плана отдельно отсчитывается от начала навигации до видимой кнопки.

| Действие | Median | p95 |
|---|---:|---:|
| Навигация → видна кнопка доступа | 133,30 мс | 248,45 мс |
| Клик «Запросить доступ» → виден диалог | 15,00 мс | 19,39 мс |
| Клик перехода → виден экран buddy | 26,60 мс | 44,60 мс |
| Отправка «Привет» → виден ответ | 31,00 мс | 41,81 мс |
| Клик «Кто мой наставник?» → виден ответ | 29,05 мс | 34,82 мс |

Сырые 10 значений каждого пути и методика: [`validation/browser_metrics.json`](validation/browser_metrics.json). Здесь нет вызова модели: последние два ответа детерминированные. Время зависит от нагрузки и железа; проверка не доказывает отклик в реальной сети. Ранний замер другого агента включал ожидание Playwright и не сопоставим с этими click→render значениями.

## Продуктовые метрики (определения, не выдуманные результаты)

- **Время до правильного действия:** от открытия плана до подтверждённого создания корректной заявки на текущий ресурс. Измерять по событиям интерфейса и ID заявки, отдельно от времени согласования наставником; сейчас **не измерено на стажёрах**.
- **Доля самообслуживания:** вопросы, после которых стажёр подтвердил полезность ответа с источником и не обратился к наставнику по той же теме, / все тематические вопросы в согласованном окне наблюдения. Сейчас **не измерена**; 16/21 автоматических model-кейсов нельзя считать этой долей.
- **Повторные объяснения наставника:** минуты на однотипные вопросы в неделю на стажёра, сравнение с базовой линией при одинаковом составе вопросов. Сейчас **не измерены**; формула 16 × 5 минут = 80 условных минут — только гипотеза, не экономия.
- **Точность подтверждённых ответов:** доля проверенных человеком атомарных утверждений, подтверждённых указанным материалом и актуальным планом; отдельно считать ошибки без источника, fallback и ошибки провайдера. Сейчас **не измерена**; контрактные 31/36 не равны этой метрике.

## Ограничения и воспроизведение

- Маленькая фиксированная выборка, один исторический полный прогон без сырого артефакта; автоматические критерии проверяют контракт, а не все факты. Прогон после retry ограничен бесплатной квотой.
- Браузер и Go замеряются на loopback без сетевого троттлинга; переносить p95 на production нельзя. Предметный ответ модели и пользовательские результаты измерять отдельно, не подменяя их локальной задержкой.
- Один синтетический стажёр, тестовые инструкции, нет реальной корпоративной авторизации: `X-Demo-User` подменяем. Действия записи требуют подтверждения в UI, модель не получает инструментов записи; для настоящей интеграции потребуются идентификация, проверка прав и договорённости об источниках.

```bash
python3 evaluate_buddy.py --delay 0 --output validation/deterministic.json
# Только если настроен действующий ключ и хватает квоты бесплатной модели:
python3 evaluate_buddy.py --live --output validation/live.json
go test ./backend ./mock-service -count=1
cd frontend && npm ci && npm test && npm run build && npx playwright install chromium
cd .. && node measure_browser.mjs --url http://127.0.0.1:5173 --samples 10
```

Eval самостоятельно поднимает два Go-процесса и временные данные; браузерный замер требует отдельно запущенных Go, mock и Vite, а также чистой позиции `backend` с открытым шагом доступа. Не коммитить ключ и реальные данные.
